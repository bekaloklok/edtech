# Fingram

**Fingram** — обучающий сайт для знакомства с русским жестовым языком. Пользователь изучает дактильный алфавит и жесты повседневных действий, смотрит образец и повторяет его.

## Актуальность

По [данным ВОЗ](https://www.who.int/ru/news-room/fact-sheets/detail/deafness-and-hearing-loss), 430 млн человек в мире нуждаются в реабилитационной помощи из-за серьёзной потери слуха. Эта цифра относится к потере слуха в целом, а не к числу пользователей жестового языка. Fingram помогает сделать первые шаги в изучении жестов и даёт обратную связь во время практики.

## Что доступно

- **Алфавит:** 33 буквы русского дактиля, образцы жестов, практика с камерой и прогресс урока.
- **Действия:** жесты повседневных слов с примерами и ссылками на видео; изученные жесты можно отметить вручную.
- **Режим «ошибка»:** сайт показывает подсказку для выбранной буквы, когда форма руки не подтверждена или нужно завершить движение.

Камера сейчас проверяет **дактильные буквы**. Распознавание жестов слов и фраз — следующий этап проекта.

## Как работает распознавание

MediaPipe определяет **21 точку кисти**. Модель на TensorFlow.js, обученная на [RSL-Dataset](https://github.com/Blockbattle/RSL-Dataset), оценивает форму буквы. Для **Д, Ё, Й, К, Щ, Ъ и Ь** сайт дополнительно проверяет движение руки. Для **З и Ц** пока проверяется только форма.

## Как открыть сайт

Репозиторий содержит готовый сайт в корневой папке. Для публикации откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку **main** и папку **/(root)**. После публикации сайт будет доступен по адресу **https://bekaloklok.github.io/edtech/**. Разрешите браузеру доступ к камере.

## Состав проекта

- `index.html`, `assets/`, `app.js`, `references/` и файлы модели — готовый сайт.
- `source/` — исходники интерфейса на React и Vite.
- `training/` — скрипты обучения и подготовки моделей.

Изображения алфавита: [abvgdee.ru](https://abvgdee.ru/alfavity/gluhonemyh). Видео жестов действий открываются на [Signflow](https://signflow.ru/about); они не входят в репозиторий.
